- доступ к данным осуществляется через регулирование доступа посредством наличия пользователя в необходимой группе AD
- отсутствует резервное копирование данных и бизнес процесс по проверке работоспособности бэкапа
- отсутствует шифрование в состоянии покоя
- отсутствует шифрование в процессе передачи данных по сети
- отсутствует защита данных во время использования
- отсутствует контроль передаваемого содержимого по почте
- данные разной категории лежат в одном месте
- отсуствует аудит действий пользователей при работе с данными
- операции с данными происходят вручную
- в архитектуре на заложены механизмы защиты данных при разработке.
- отсуствует Data Lineage
