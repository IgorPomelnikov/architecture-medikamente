## Общие рекомендации

Обязательное внедрение аутентификации через SSO с использованием Authorization code flow + PKCE, передача данных только по зашифрованным протоколам, хранение сессий в распределенном кэше, доступ к данным через ABAC. Внедрить Data Lineage, и на ближайшей перспективе до внедрения DWH/DL тегировать данные вручную через СУБД. Настроить мониторинг систем, аудит логирование, структурированное логирование, балансировщики нагрузки.  Подключить SIEM и SOAR системы. Хранение ключей приложений организовать в специальных vault. Добавить S3 хранилище для ухода от хранения больших файлов в БД или файловой системе.
